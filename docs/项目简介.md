# 申报系统 - 项目简介

## 一、项目概述

**申报系统**是一个基于 **Spring Boot + Maven + React** 的全栈 Web 应用，为活动申报者提供在线填报服务。系统支持用户注册/登录、申报信息填报、文件上传、状态管理等完整业务流程。

## 二、技术栈

### 后端（Spring Boot + Maven）

- **框架**：Spring Boot 2.7.18（基于Spring Framework 5.x）
- **构建工具**：Maven 3.x
- **数据访问**：MyBatis + H2数据库（开发）/ MySQL（生产）
- **认证**：JWT（jsonwebtoken 0.11.5）
- **密码加密**：Spring Security BCryptPasswordEncoder
- **验证**：Spring Validation（JSR-303）
- **跨域**：Spring MVC CORS配置
- **开发工具**：Spring Boot DevTools、Lombok

### 前端（React）

- **框架**：React 18.2.0
- **路由**：React Router v6
- **UI组件库**：Ant Design 5.x
- **HTTP客户端**：Axios
- **构建工具**：Create React App（Webpack）

## 四、核心功能

### 1. 用户认证

- **注册**：手机号+短信验证码+密码+真实姓名+证件信息
- **登录**：支持密码登录和短信验证码登录
- **一键测试登录**：无需注册，自动创建测试账号
- **JWT认证**：无状态认证，token有效期7天
- **密码加密**：BCrypt哈希，不可逆加密

### 2. 申报管理

- **创建申报**：三步表单（选择项目→基本信息→详细信息）
- **编辑申报**：仅未提交的申报可编辑
- **提交申报**：检查必填信息完整性
- **撤回申报**：已提交的申报可撤回为草稿
- **删除申报**：仅未提交的申报可删除
- **查看申报**：分节展示详情

### 3. 文件上传

- **单文件上传**：支持图片、PDF、视频、音频
- **多文件上传**：最多5个文件
- **文件限制**：单文件最大50MB
- **文件存储**：本地磁盘存储

### 4. 证件验证

- **证件类型**：居民身份证、护照、港澳、澳门、台湾
- **号码校验**：前端+后端双重验证
- **强规则校验**：提交时身份证号校验

## 五、启动方式

### 1. 启动后端

```bash
cd backend
# 使用Maven打包
mvn clean package
# 运行
java -jar target/submission-system-1.0.0.jar
# 或
mvn spring-boot:run
```

### 2. 启动前端

```bash
cd frontend
npm install
npm start
```

### 3. 访问

- 前端：`http://localhost:3000`
- 后端：`http://localhost:8080/api`
- H2控制台：`http://localhost:8080/api/h2-console`
