# 项目手册 - 申报系统（Spring Boot + Maven + React）

## 一、项目概述

**申报系统**是一个基于 **Spring Boot + Maven + React** 的全栈 Web 应用。系统为活动申报者提供在线填报服务，支持用户注册/登录、申报信息填报、文件上传、状态管理等完整业务流程。

## 四、核心文件详解

### 4.1 pom.xml

Maven 依赖配置文件，定义所有后端依赖。

**关键依赖：**

- `spring-boot-starter-web`：Web 支持
- `mybatis-spring-boot-starter`：MyBatis 集成
- `h2`：H2 内存数据库（开发）
- `mysql-connector-java`：MySQL 驱动（生产）
- `jjwt-api/jjwt-impl/jjwt-jackson`：JWT 支持
- `spring-security-crypto`：BCrypt 密码加密
- `lombok`：简化代码（需配置 annotationProcessorPaths）
- `spring-boot-starter-validation`：参数验证

**重要配置：**

- `lombok` 版本固定为 `1.18.30`，scope 为 `compile`
- `maven-compiler-plugin` 配置 `annotationProcessorPaths` 显式指定 Lombok 注解处理器
- `spring-boot-maven-plugin` 打包可执行 JAR

### 4.2 application.yml

Spring Boot 应用配置文件。

```yaml

```

### 4.3 schema.sql

H2 数据库初始化脚本，应用启动时自动执行。

**注意：** H2 数据库不支持 `INDEX` 内联在 `CREATE TABLE` 中，需单独创建：

```sql
CREATE TABLE IF NOT EXISTS t_user (...);
CREATE UNIQUE INDEX IF NOT EXISTS idx_phone ON t_user(phone);
```

### 4.4 JwtInterceptor.java

JWT 认证拦截器，实现 `HandlerInterceptor` 接口。

**关键逻辑：**

1. 放行 `OPTIONS` 预检请求（CORS）
2. 从 `Authorization` 头提取 token（格式：`Bearer <token>`）
3. 使用 `JwtUtil.validateToken` 验证 token
4. 解析 userId，存入 `request.setAttribute("userId", userId)`

### 4.5 WebConfig.java

Web 配置类，实现 `WebMvcConfigurer`。

- `addCorsMappings`：配置 CORS，允许所有来源
- `addInterceptors`：注册 JwtInterceptor，排除 `/auth/**` 路径

### 4.6 Result.java

统一响应结果类，使用泛型 `<T>`。

```java
@Data
public class Result<T> {
    private Integer code;
    private String message;
    private T data;
    
    public static <T> Result<T> success(T data) {
        Result<T> result = new Result<>();
        result.setCode(200);
        result.setMessage("操作成功");
        result.setData(data);
        return result;
    }
    
    public static <T> Result<T> error(Integer code, String message) {
        Result<T> result = new Result<>();
        result.setCode(code);
        result.setMessage(message);
        return result;
    }
}
```

**前端访问方式：** `res.data.data`（第一个 data 是 axios 的响应体，第二个 data 是 Result 中的业务数据）

### 4.7 User.java / Submission.java

实体类，使用 Lombok `@Data` 注解自动生成 getter/setter。

**User 新增字段：**

- `token`：JWT token（不存入数据库，仅用于响应）

### 4.8 api.js

前端 API 服务层封装。

```javascript
const API_BASE_URL = process.env.REACT_APP_API_URL || 'http://localhost:8080/api';

// 请求拦截器：自动添加 token
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 响应拦截器：统一处理 401
api.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem('token');
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);
```

### 4.9 SubmissionCreate.js

创建申报页面，使用三步表单。

**关键实现：**

- 所有步骤的字段始终渲染在 DOM 中，使用 CSS `display: none` 隐藏非当前步骤
- 这样 `form.getFieldsValue(true)` 可以获取所有字段的值
- 文件上传使用完整 URL：`action="http://localhost:8080/api/upload"`

### 4.10 Home.js

申报列表页面。

**关键实现：**

- 响应数据结构：`res.data.data`（Result 包装器）
- 字段映射：`dataIndex: 'createTime'`（Java 实体字段名）
- 操作按钮使用 `record.id`（Java 实体的 Long id）

## 六、开发过程中遇到的问题及解决方案

### 6.1 Lombok 注解处理器未生效

**问题：** 编译时找不到 `setCode`、`getPhone` 等 Lombok 生成的方法。

**原因：** `lombok` 依赖的 scope 为 `provided`，Maven 编译器不会自动处理注解处理器。

**解决：**

1. 将 `lombok` 的 scope 改为 `compile`
2. 在 `maven-compiler-plugin` 中配置 `annotationProcessorPaths`：

```xml
<annotationProcessorPaths>
    <path>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <version>1.18.30</version>
    </path>
</annotationProcessorPaths>
```

### 6.2 H2 数据库语法不兼容

**问题：** `schema.sql` 执行失败，报错 `Unknown data type: "IDX_PHONE"`。

**原因：** H2 不支持 `CREATE TABLE ... INDEX idx_name (column)` 的 MySQL 语法。

**解决：** 将索引单独创建：

```sql
CREATE TABLE IF NOT EXISTS t_user (...);
CREATE UNIQUE INDEX IF NOT EXISTS idx_phone ON t_user(phone);
```

### 6.3 CORS 预检请求被拦截

**问题：** 前端发送 `OPTIONS` 预检请求，返回 401。

**原因：** JwtInterceptor 拦截了所有请求，包括 CORS 预检请求。

**解决：** 在 JwtInterceptor 中放行 OPTIONS 请求：

```java
if ("OPTIONS".equalsIgnoreCase(request.getMethod())) {
    return true;
}
```

### 6.4 前端响应数据结构不匹配

**问题：** 后端返回 `Result<T>`，前端直接访问 `res.data` 获取不到业务数据。

**原因：** Spring Boot 使用统一响应包装器，axios 的 `res.data` 是 `Result` 对象。

**解决：** 前端访问 `res.data.data`：

```javascript
const res = await submissionAPI.getList();
setSubmissions(res.data.data || []);
```

### 6.5 前端字段名不匹配

**问题：** MongoDB 使用 `_id`，Java 使用 `id`；MongoDB 使用 `createdAt`，Java 使用 `createTime`。

**解决：** 前端统一使用 Java 字段名：`record.id`、`dataIndex: 'createTime'`。

### 6.6 三步表单字段丢失

**问题：** 创建申报时，只提交了第三步的字段，第一步和第二步的字段丢失。

**原因：** React 组件卸载时，Ant Design Form 的字段值被清除。

**解决：** 所有步骤的字段始终渲染在 DOM 中，使用 CSS `display: none` 隐藏：

```jsx
<div style={{ display: currentStep === 0 ? 'block' : 'none' }}>
  <Form.Item name="category">...</Form.Item>
</div>
```

### 6.7 后端未返回 token

**问题：** 登录成功后，前端无法获取 token。

**原因：** 后端 `UserService` 生成了 token，但没有设置到 User 实体中返回。

**解决：** 在 User 实体中添加 `token` 字段，登录时设置：

```java
user.setToken(token);
```

## 七、启动方式

### 1. 编译后端

```bash
cd backend
mvn clean package
```

### 2. 运行后端

```bash
java -jar target/submission-system-1.0.0.jar
```

### 3. 运行前端

```bash
cd frontend
npm install
npm start
```

### 4. 访问

- 前端：`http://localhost:3000`
- 后端：`http://localhost:8080/api`
- H2 控制台：`http://localhost:8080/api/h2-console`
